# 一级子任务

用户已选择一级子任务规则：每个父任务可以添加、编辑、独立勾选、删除子任务，列表可展开/折叠并显示已完成/总数。父任务仍手动完成，子任务随父任务移动、保存、归档和历史恢复。文字沿用 Enter 提交并新增下一项、Shift+Enter 换行、IME 确认不提交。

沿用 React/Tauri 与现有视觉样式，借鉴 WeekToDo 的子任务清单及其明确展开入口需求（https://github.com/manuelernestog/weektodo/issues/192），不复用外部代码。

实现选择：Task 新增可选 subtasks 数组；Subtask 含 id/text/completed/createdAt/updatedAt，不增加多级关系。旧任务无此字段时不重写，损坏或重复 ID 的子任务拒绝加载/写入，不能悄悄过滤。父任务空标题但有子任务时保留。父任务完成不改变子项状态；子项全部完成也不自动完成父任务。

保存与本地保护：子任务文字修改只更新草稿；Enter、勾选、删除、主界面保存和正常关闭沿用提交路径。展开/折叠不提交文字草稿。原生日志和历史必须完整保存子任务，仓库/历史预览显示子任务及状态，仓库搜索包含子任务文字。保持旧历史、备忘录、日记、图片、设置及未知字段兼容。

同步边界：现有已部署服务及旧手机仅理解旧任务字段，因此本次子任务先保存在本机。向旧服务发送时去掉 subtasks，本地接收父任务更新时保留已有子任务；云端删除仍遵守原父任务合并规则，删除前完整历史保留子项。界面说明“子任务保存在本机”。不发布云服务或 Android 更新，不承诺子任务已跨设备同步。

验证：模型增删改与父子独立状态、旧任务兼容、损坏数据拒绝、历史 round-trip、本地提交重载、父任务更新不丢子项、父任务归档/恢复、任务移动、Enter/Shift+Enter/IME、折叠不提交草稿、720/520 宽度。浏览器使用 mock IPC 与独立资料目录，不启动原生 Tauri 测试实例，不以更改 APPDATA 作为隔离。
