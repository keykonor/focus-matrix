# Subtasks Implementation Plan

> **For agentic workers:** Use executing-plans to implement this plan task-by-task.

**Goal:** Add one-level, independently completed subtasks to desktop tasks without losing existing content.

**Architecture:** Optional nested arrays preserve old task shapes. A focused editor component and pure model helpers integrate with existing explicit save requests. Native history and validation retain the new fields; cloud projections exclude local-only subtasks and restore them when receiving parent updates.

**Tech Stack:** React 19, TypeScript, Vitest, Tauri/Rust, isolated Edge mock-IPC regression.

**Spec:** docs/superpowers/specs/2026-11-04-subtasks-design.md

## Global Constraints

- One subtask level; parent and child completion are independent.
- Enter submits and adds the next row; Shift+Enter and IME do not submit.
- Preserve existing tasks, memos, diaries, settings, images, history, archives and unknown store fields.
- Subtasks remain local; old cloud responses cannot strip them from surviving parent tasks.
- No native test instance or real user data mutation for testing.

## Review Focus

- Empty parent titles with child content survive blur.
- Malformed child arrays stop writes instead of being partially discarded.
- Parent cloud changes preserve local children, including conflicts.
- Collapse/expand does not commit unsaved text.
- Archive and history retain and display children after reload.
