# Focus Matrix 第一部分产品改进

状态：第一部分已于 2026-11-14 完成本机安装和数据核对。第二部分的标准版/离线版、公共账号和完整云同步协议不在本次部署范围。

## 分工

- Sol UI：顶栏常驻导入；合并同步与分享、历史与仓库；外观设置与键盘可用性。
- Sol 导入：日期证据、参考日期、简短描述、原文/图片预览、重复检测与取消。
- Sol 日程领域：结构化日程、重复日期投影、批次撤销、提醒去重和验证。
- 主代理：数据兼容、历史、主界面与日历接线、任务关联、Windows 提醒、回归与本机安全更新。

## 六项交付及验收

- [x] 统一日程记录：保留全部旧自由文字/附件，新增结构化事项；两种布局使用同一记录，切换保留精确时间；可编辑/完成/关联待办。
- [x] 日期可靠性：消息日期/参考日期/最近星期、跨月年与多个事项绑定证据；不确定结果需核对，短描述不输出长分析。
- [x] 可信导入：批量截图、原文与结果对照、重复过滤、取消；导入批次持久化，重启后可撤销且不抹掉后续修改。
- [x] 执行提醒：精确日程可设置提前提醒、每日/每周重复；运行/托盘时提醒，当日唤醒补查，完成去重；完全退出/关机不宣称通知可达。
- [x] 同步体验：统一入口，明确连接/待重试/本地保存范围；保留原账号与配对；不以健康200声称全字段同步，服务端协议升级另属第二部分。
- [x] 设置与状态：窗口/外观/记录/同步/智能分组，低饱和主题和密度；任务仍Enter提交，显示未提交状态，不恢复按键实时保存。

## 数据保护与依赖

新增可选 agenda 字段，旧数据缺字段不补写；读坏数据停止写入。历史保存 agenda，但待办历史恢复继续只替换待办。
任务关联使用 agenda.event.taskId，不给旧云端任务引入未支持字段。关联的重复日程不自动改变未来日期任务完成状态。
保留 settings、dailyMemos、dailyMemoSchedules、dailyDiaries、completedTasks、历史、附件、窗口状态和 DPAPI 云凭据。
第一部分只能陈述本地能力与现有同步范围，不能把小时日程、日记、附件、子任务称为已跨端。

## 验证与更新

纯领域与持久化失败保护单元测试；Rust 历史/数据校验；隔离浏览器导入/撤销/布局/记录与提醒 IPC 验收。
覆盖 520/720/1200 宽度；不往真实任务写测试内容，不通过重定向 APPDATA 假装隔离原生应用。
正式 npm run tauri build -- --no-bundle 后执行 scripts/install-local.ps1；nonce 保存退出失败不能强杀。
使用安装前完整快照比对；仅已授权数据新增可接受，已有字段/文件不可覆盖。完成后再次保存源码版本。
