# 一级子任务更新 · 2026-11-04

用户选择一级子任务清单，父任务手动完成。参考 [WeekToDo](https://github.com/manuelernestog/weektodo) 的子任务能力和 [明确展开入口的需求反馈](https://github.com/manuelernestog/weektodo/issues/192)，沿用当前桌面界面实现，没有引入新依赖或复制外部源码。

每个任务下方新增“添加子任务”。子任务独立新增、编辑、勾选、删除，展开/收起旁显示已完成/总数。Enter 提交并新增子任务，Shift+Enter 换行，IME 确认不提交；折叠不提交草稿。勾选父任务不联动子任务，子任务全部勾选不自动完成父任务。鼠标和 Tab→Enter 都能在空标题任务中添加子任务；已有子任务的空标题父任务不被 blur/Delete 清理。

Task 新增可选 subtasks 数组。旧任务无此字段时不补写，损坏列表、重复 ID 或多级数据停止加载/保存。原生历史保持子任务及额外字段，仓库快照去重包含子任务，历史和仓库展示子任务及状态，仓库搜索覆盖子任务文字。

子任务暂时仅保存在本机，不发送给现有云服务或旧手机；接收云端父任务更新时保留本地子任务及有效修改时间，父任务冲突副本也保留子任务。云端删除继续遵守现有任务合并规则，保存前历史保留完整记录。未部署云端或 Android，不能声称子任务已跨设备同步。
