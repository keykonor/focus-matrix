# 2026-10-26 回车提交保存更新

用户明确选择“仅取消输入文字时的实时保存”。任务文字输入后不再由 400 毫秒停顿触发保存；Enter 保存当前内容并新增下一项，Shift+Enter 只换行，中文输入法选字确认不提交。顶部手动保存保留。勾选、删除、拖动、正常隐藏/退出、日期备忘录、设置和午夜归档继续保存。

## 实现与验证

- `App.tsx` 将任务输入与提交保存分开，Enter 以及任务状态操作在 React 更新完成后请求保存。保留原有事务锁、退出幂等、更新 nonce 和历史保护，不改数据格式。
- 后台云同步在任务有未提交修改时等待；发送读取持久化基线，不取正在输入的瞬时状态。网络返回时若产生新草稿，不覆盖、不提前确认远程回执。手动“立即同步”仍是显式保存并同步操作。
- 新浏览器用例先在旧实现上复现“未按回车已自动保存”的失败，再验证输入、在线事件触发后台同步均不提交草稿；Enter 保存并新增，Shift+Enter 和 IME 不提交；保存期间可继续输入但后续文字等下一次提交，失败草稿保留并可手动重试。
- 完整 37 项 Vitest、TypeScript/Vite 构建、公开源码检查通过。完整归档/午夜/布局/事务交互浏览器回归通过，备忘录和待办历史恢复独立浏览器回归通过。备忘录继续自动保存，历史恢复仍只替换任务、保留当前备忘录。
- 适配旧浏览器回归对实时保存的预期，使用显式提交；历史较多时用实际“显示更早”分页按钮。独立日历脚本使用唯一资料目录并等待页面加载事件，避免旧资料目录和重载旧 DOM 造成误判。测试均使用合成内容，没有在真实任务上增加测试项。
