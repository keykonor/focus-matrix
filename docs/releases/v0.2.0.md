# Focus Matrix 0.2.0

首次在 GitHub 公开发布：Windows 四象限任务便笺，包含日期备忘录、内容历史、已完成仓库和午夜归档。

## 下载与安装

- Windows 10/11 x64：下载 **FocusMatrix-Windows-x64-setup.exe**。
- 安装器由本仓库 GitHub Actions 的 Windows runner 构建。
- 下载后可用 `Get-FileHash -Algorithm SHA256` 与 **SHA256SUMS.txt** 核对。
- **release-provenance.json** 记录准确源码提交、版本、架构和构建运行链接。
- GitHub 自动附带的 Source code 压缩包是源码，不是安装器。

## 本次整理

- 采用 MIT，保留第三方许可声明及真实源码历史。
- 自动运行前端、原生、更新快照、隔离浏览器和安装器检查后再发布。
- 安装/卸载前拒绝覆盖运行中的程序，并先创建带校验值的本地备份。
- 保留任务、日期备忘录、仓库、设置、窗口状态、内容历史和加密配置。

## 升级须知

先保存工作，在系统托盘右键选择“退出”，然后运行安装器。窗口右上角 × 默认只是隐藏到托盘。
安装器不会强杀旧程序；备份失败会停止。卸载保留数据，重新安装后继续使用。
旧版本地脚本的安装路径与此安装器的默认路径可能不同；原有本机脚本仍用于维护原路径，不要直接用新 EXE 覆盖正在运行的旧 EXE。

## 已知限制

- 当前安装器未做 Windows 数字签名。
- 已有云端集成需要单独配置私人凭据，下载软件不会获得维护者的云账户或写入密钥。
- 云同步最近一次已有验收记录为 2026-10-17 HTTP 410，当前发布不声称恢复；分享网页导航也有既有托管限制。
- 已完成仓库只在本机保存。Android 真机覆盖安装和同步没有完整验收，本次不发布新 Android 包。
- 安装器检查在 GitHub 的隔离 Windows runner 上执行，不能代替所有 Windows 环境的真机验证。
