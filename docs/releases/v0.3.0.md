# Focus Matrix 0.3.0

在 0.2.0 基础上新增子任务、文档与图片附件、日期备忘录附件、每日日记、时间段安排、点击网址直接打开，以及多处界面与保存交互改进。

## 下载与安装

- Windows 10/11 x64：下载 **FocusMatrix-Windows-x64-setup.exe**。
- 安装器由本仓库 GitHub Actions 的 Windows runner 构建。
- 下载后可用 `Get-FileHash -Algorithm SHA256` 与 **SHA256SUMS.txt** 核对。
- **release-provenance.json** 记录准确源码提交、版本、架构和构建运行链接。
- GitHub 自动附带的 Source code 压缩包是源码，不是安装器。

## 本次更新

- 一级子任务：每任务一条清单，独立增删改/勾选，父任务手动完成；历史与仓库保留子项。
- 任务文档与图片：可多选本地文档、拖入或粘贴图片，文档用默认应用打开只读副本，图片显示缩略图可放大。
- 日期备忘录附件：早上/下午/晚上与 24 小时各时段都可添加文件、图片和网页链接，拖入或粘贴即可，随本机数据保存。
- 点击网址直接打开：任务与日期备忘录里的网址文字本身即可点击打开，不再显示单独的「打开链接」按钮。
- 每日日记：按所选日期独立保存，随历史快照保留。
- 时间段安排：可切换 24 小时或早上/下午/晚上，按小时选择显示。
- 本地图片/链接：粘贴或拖入任务，历史与完成仓库可预览。
- 文件传输修复：支持 Windows 原生文件拖放与复制粘贴，一次性授权导入并保留原描述。
- 跨日自动归档：本地午夜自动归档已完成任务，无需手动操作。
- 输入与保存：Enter 保存并新增下一项，Shift+Enter 换行，IME 选字确认不提交；保存失败保留草稿。

## 升级须知

先保存工作，在系统托盘右键选择“退出”，然后运行安装器。窗口右上角 × 默认只是隐藏到托盘。
安装器不会强杀旧程序；备份失败会停止。卸载保留数据，重新安装后继续使用。
旧版本地脚本的安装路径与此安装器的默认路径可能不同；原有本机脚本仍用于维护原路径，不要直接用新 EXE 覆盖正在运行的旧 EXE。

## 已知限制

- 当前安装器未做 Windows 数字签名。
- 云端集成需要单独配置私人凭据，下载软件不会获得维护者的云账户或写入密钥；云同步与分享网页仍有既有限制，本次不声称恢复。
- 已完成仓库只在本机保存。Android 真机覆盖安装和同步没有完整验收，本次不发布新 Android 包。
- 安装器检查在 GitHub 的隔离 Windows runner 上执行，不能代替所有 Windows 环境的真机验证。
