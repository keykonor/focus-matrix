# Focus Matrix 0.4.0

Windows 10 22H2／Windows 11，x64。两个版本使用同一套本地任务、日历与历史数据。

| 下载 | 内容 |
| --- | --- |
| 标准版 `FocusMatrix-Windows-x64-setup.exe` | 默认推荐。安装后即可使用四象限、日程和备忘录。首次使用聊天识别，在「导入信息 → 配置本机识别」打开 Ollama 下载页，安装并启动 Ollama 后下载 Qwen3.5 4B。 |
| 离线版 `FocusMatrix-Windows-x64-offline.zip` | 下载启动 ZIP、`FocusMatrix-Offline-Ollama.zip`、`FocusMatrix-Offline-Qwen.bin.01`、`FocusMatrix-Offline-Qwen.bin.02`、`FocusMatrix-Offline-Qwen-vision.bin`，放在同一目录。把启动 ZIP 解压到子文件夹，运行其中的 `install-offline.cmd`。自带 WebView2、Ollama 和模型，目标电脑安装与识别均可断网。 |

使用 `SHA256SUMS.txt` 校验文件。离线版请预留约 9 GB 系统盘空间。升级前在系统托盘退出旧版，安装器会校验备份现有数据。重新安装后继续使用原任务与记录。

离线安装器的下载校验值以发布页的 `SHA256SUMS.txt` 为准。标准安装器的签名状态记录在 `release-provenance.json`。

- 四宫格和日历顶栏均可打开聊天导入。批量截图及文字识别后可核对原文、日期、时间并撤销最近一批。
- 日历支持结构化日程、重复、提醒和关联待办，切换两种布局可保留具体时间。
- 合并「历史与仓库」「同步与分享」。设置分组，可调整主题和间距。

聊天 OCR 和模型推理在本机运行。手机同步和网页分享需要单独配置云服务。独立日程、提醒及导入批次保存在本机。
