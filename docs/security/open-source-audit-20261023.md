### npm 优先处理项

`cloud-site` 的 Next.js 锁定版本为 16.3.4，npm 将其归为 critical。
[上游公告 GHSA-vcvr-r3jv-pc5j](https://github.com/advisories/GHSA-vcvr-r3jv-pc5j)
涉及 `next/og ImageResponse`；另有其他 Next.js 公告，不能只按单个公告的修复版本结束整改。
本次源码搜索未找到显式 `next/og` 或 `ImageResponse` 用法；这不是排除所有框架间接调用的证明。
需要确认实际部署使用的 vinext/Next 路径、受影响功能是否启用，以及线上构建对应的准确锁文件。

其他受影响的直接依赖包括 `@cloudflare/vite-plugin`、`react-server-dom-webpack`、
`vinext`、`vite`、`wrangler`、`eslint-config-next`、`drizzle-kit`。
不能直接执行 `npm audit fix --force`：审计建议中存在跨大版本或降级的替换，必须逐组评估、
更新锁文件并测试。开发工具漏洞要结合是否向外暴露开发服务评估，不能自动当成生产 RCE。
